# 木子汐角色设计稿

本文档记录木子汐当前已实现的角色规则、卡池、遗物、药水和 Power，以及后续验证所需的设计约定。第 4-7 节所列 61 张卡牌均已有对应源码、本地化和图片资源。

木子汐是一个独立于九大剑术体系的绿色角色。她围绕“生机”和“一体双魂”构筑：木子汐人格偏向防御和积累，泪汐儿人格偏向消耗和爆发。两个人格共用同一副牌组和生命值，通过人格牌切换。

### 1.1 初始内容与通用牌

- 神魔瞳在每场战斗开始时进入木子汐人格，并获得 2 点生机。
- 角色的事件起始卡为根脉守护。
- “打击”和“防御”是所有角色都应拥有的通用基础牌；木子汐的实现可以继续使用现有 `MuzixiStrike` 和 `MuzixiDefend` ID，但显示名称不加角色前缀。木子汐的四张 `BASIC` 卡全部属于初始牌组：4 张打击、4 张防御、1 张生机奔涌和 1 张生命汲取。
- 木子汐的打击带有本体 `STRIKE` 与 `STARTER_STRIKE` 标签，防御带有 `STARTER_DEFEND` 标签，以兼容潘多拉魔盒及其他按打击或起始牌标签判定的本体效果。
- “人格交替”是普通稀有度的卡牌，不属于基础牌，也不再放入初始牌组；人格切换由神魔瞳和后续卡池提供。

## 2. 核心规则

### 2.1 术语和结算约定

- “获得 / 失去生机”指修改 `Vitality` Power 的层数；“消耗 X 点生机”指资源支付，不等同于卡牌的“消耗”（Exhaust）。获得生机时先处理凋萎，生机始终不能低于 0。
- “消耗”单独出现在卡牌类型描述中时，表示卡牌打出后进入消耗牌堆；建议本地化文本尽量写成“本牌消耗”，避免和生机支付混淆。
- “至少有 X 点”检查效果结算时的当前层数；“最多消耗 X 点”实际消耗量不得超过当前可用层数。消耗生机的牌只能支付已有生机，不能把生机消耗到 0 以下。
- “获得生机”先抵消已有的 `Wither`（凋萎）层数，但不撤销已经记录的负临时最大生命；只有超出凋萎层数的部分才转化为生机。生机与凋萎互斥，生机始终不能低于 0。
- “失去生机”先扣除当前生机；如果失去量超过当前生机，超出的部分转化为凋萎，不继续降低生机。每新增 1 层凋萎，立即扣除 1 点本场战斗的临时最大生命（最大生命最低保留 1 点）；凋萎每层只影响临时最大生命，不额外扣除当前生命。
- “吸取 X 点生机”指目标失去 X 点生机、自己获得 X 点生机。目标生机不足时，超出部分仍按“失去生机”规则转化为凋萎；自己始终获得完整的 X 点生机，不受目标当前生机数量影响。
- 卡牌升级只改变表中明确列出的项目；未列出的费用、类型、目标和状态保持不变。
- 文档中的“真实伤害”统一沿用本体 `DamageInfo.DamageType.HP_LOSS` 结算；目前神之泪、死之眼和灵魂倒影的降血分支均使用该类型。

### 2.2 生机

生机是战斗内资源，以 `Vitality` Power 层数显示，始终为非负数。获得生机时先按 1:1 抵消凋萎层数，但不会在战斗中恢复凋萎已经扣除的临时最大生命；抵消完凋萎后的剩余获得量才增加生机，并使本场战斗的临时最大生命增加等量。当前生命不会因获得生机同时增加；生机之后被消耗或被吸取时，已经增加的临时最大生命也不会在战斗内减少。所有正负临时最大生命变化均由独立 Power 记录，并只在战斗结束时统一撤销。

失去生机时，先从当前生机中扣除可扣除的部分；超出当前生机的部分按 1:1 增加凋萎。每层凋萎扣除 1 点本场战斗的临时最大生命，但不直接扣除当前生命；生机和凋萎不会同时为正，且凋萎不会使生机变成负数。凋萎与临时最大生命均在战斗结束时清除。

生机的设计目标是“先积累，再把资源转成一次性收益”，而不是永久生命成长。卡牌中的“拥有至少 X 点生机”检查当前层数，“消耗 X 点生机”在结算时最多消耗实际拥有的层数。

### 2.3 麻痹

麻痹是施加在敌人身上的可叠加临时状态，建议 ID 为 `NineSwordTechniques:Paralysis`。每获得 1 层麻痹，目标本回合的力量和敏捷各降低 1；在目标回合结束时清除本回合的麻痹，并恢复被降低的力量和敏捷。它不是永久削弱，也不应跨回合保留。

同一回合内追加麻痹时，追加几层就追加几层属性降低；清除 N 层麻痹就恢复 N 点力量和 N 点敏捷，且必须只恢复本 Power 实际降低的数值，避免和其他减力量、减敏捷效果互相覆盖。目标死亡、战斗结束或 Power 被强制移除时也要完成清理。

卡牌描述中的“目标有 X 层麻痹”指结算瞬间的当前层数。麻痹流派应围绕“施加、达到阈值、在清除前引爆”循环，不依赖无限叠层；单张牌的麻痹伤害或收益应设置上限。

### 2.4 人格

人格是可跨角色使用的状态，不与 `MuzixiCharacter` 类型绑定：

- 木子汐人格：每回合开始获得 3 点格挡和 1 点生机。
- 泪汐儿人格：进入该人格时，最多消耗 9 层灵魂共鸣；每消耗 1 层，抽 1 张牌并获得 1 点能量，未消耗的层数保留。
- 无人格状态：角色同时没有木子汐人格和泪汐儿人格标记时，不触发任何人格效果。
- 无人格状态下首次执行人格交替固定进入木子汐人格。
- 任意角色通过外部效果获得对应人格 Power 后，都应触发对应效果；其他角色不会默认获得任何人格。
- 人格不跨战斗保留：战斗结束时统一静默清除两种人格标记，下一场战斗从无人格状态开始，再结算神魔瞳等战斗开始效果。木子汐持有神魔瞳时，随后进入木子汐人格并获得 2 点生机。

## 3. 卡池结构

当前共实现 61 张专属卡牌。

| 稀有度 | 数量 |
| --- | ---: |
| 基础 | 4 |
| 普通 | 24 |
| 罕见 | 24 |
| 稀有 | 9 |
| 合计 | 61 |

基础卡的代码和稀有度以第 4 节表格为准；四张卡均按 `BASIC` 稀有度处理，并全部进入初始牌组。`PersonaShift`（人格交替）按 `COMMON` 稀有度处理，不属于初始牌组。

- 生机主轴：积累生机、根据当前生机达到阈值、消耗生机转化为格挡、治疗、抽牌或能量。
- 麻痹主轴：对敌人施加麻痹、根据麻痹层数获得额外效果、在敌人回合结束前引爆麻痹。
- 人格与混合牌：提供切换、灵魂共鸣以及同时连接两条主轴的收益，避免卡组只能单走一个方向。

## 8. 流派与构筑目标

### 8.1 生机流

生机流的基本循环是“通过萌芽、落叶舞、生机奔涌和世界树积累资源，使用阈值牌获得额外收益，再用生机护体、根脉重击、生机淬炼等牌把资源转化为格挡、伤害、抽牌或能量”。万花提供从敌方 Power 获取生机的独立路径。卡组需要同时提供防御和有限治疗，避免只靠临时最大生命拖延战斗。

### 8.2 麻痹流

麻痹流的基本循环是“用花粉、根须和藤蔓施加麻痹，在目标回合结束前利用断脉、麻痹收割和神经断灭取得收益”。绝对麻痹可以改变麻痹的清除节奏。玩家需要安排出牌顺序，而不是无条件地长期堆叠。

### 8.3 人格与混合流

人格交替先获得灵魂共鸣，再切换人格；生之眼和死之眼用于直接进入指定人格，觉醒提供一次性切换，神魔之眼负责集中积累灵魂共鸣，两仪归一则把人格切换连接到生机和麻痹。人格效果必须由 Power 持有者触发，不依赖持有者是否为木子汐。

人格切换通过统一动作完成：先获得灵魂共鸣，再判断当前人格、移除旧人格、施加新人格并触发进入效果。由于其他角色也可能直接获得泪汐儿人格，灵魂共鸣的转化由统一的“进入泪汐儿人格”逻辑负责，而不只写在 `SwitchPersonaAction` 中。无人格状态下首次执行“切换人格”固定进入木子汐人格，仍遵循“先获得灵魂共鸣、再切换”的顺序，并计作一次切换以触发两仪归一；直接进入指定人格的效果不按此规则额外计作切换。战斗结束时以不触发人格切换效果的方式静默清除人格；因此每场战斗的边界状态均为无人格，神魔瞳随后通过战斗开始效果进入木子汐人格。

世界树应监听玩家当前能量值的实际变化：能量每下降 1 点就获得 1 点生机，单次从 E 降至 E-k 按 k 次触发，能量增加不触发；能量上限变化本身不单独触发，只有当前能量值实际下降才触发。不根据卡牌费用推算，也不区分普通费用、临时降费或其他造成能量下降的来源。麻痹需要独立的敌方 DEBUFF Power；万花需要对每个敌人独立拍摄 BUFF/DEBUFF 快照，按有层数取绝对值、无层数计 1 层后一次性结算，快照之后的 Power 变化不影响本次结果；神经断灭等牌还需要专用动作计算实际移除的麻痹层数。

## 11. 药水现状

当前没有木子汐专属药水类、药水注册或药水本地化条目。角色使用游戏本体和其他模组提供的通用药水。后续若加入专属药水，应同时补充药水实现、BaseMod 注册入口、ZHS/ENG 本地化、图标资源和角色专属掉落规则。

## 12. 测试重点

重点检查：生机获得后临时最大生命是否正确显示且不误回血；消耗生机是否不会在战斗中造成意外扣血；超额失去生机是否只增加凋萎；麻痹在敌方回合结束时是否完整清理并恢复属性；麻痹回响在每个玩家回合的群体首个有效目标上只重复一次且不递归；世界树对能量差值逐点触发、能量增加不触发；万花按每个敌人的结算前快照独立计算；神之泪、死之眼和灵魂倒影的降血分支是否使用 `HP_LOSS`；灵魂倒影是否始终至少保留 1 点生命；无人格状态是否完全无额外效果；其他角色获得人格 Power 后是否按同样规则触发；所有依赖“当前麻痹层数”和“当前生机层数”的牌是否在清除或消耗前完成判定。
