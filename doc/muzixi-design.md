# 木子汐角色设计稿

本文档是木子汐的下一版设计草案，描述目标卡池和规则，不代表全部内容已经实现。当前源码仍有 25 张木子汐卡牌；本稿在保留现有设计方向的基础上，扩展为 60 张专属卡牌，供后续实现和平衡测试使用。

木子汐是一个独立于九大剑术体系的绿色角色。她围绕“生机”和“一体双魂”构筑：木子汐人格偏向防御和积累，泪汐儿人格偏向消耗和爆发。两个人格共用同一副牌组和生命值，通过人格牌切换。

## 基础设定

- 角色 ID：`NineSwordTechniques:Muzixi`
- 初始生命：70；初始能量：3；初始金币：99。
- 初始牌组：5 张打击、4 张防御、1 张人格交替。
- 初始遗物：神魔瞳。
- 角色卡牌颜色：`MUZIXI_GREEN`，显示为青绿色。
- 神魔瞳在每场战斗开始时进入木子汐人格，并获得 2 点生机。
- 角色的事件起始卡为根脉守护。
- “打击”和“防御”是所有角色都应拥有的通用基础牌；木子汐的实现可以继续使用现有 `MuzixiStrike` 和 `MuzixiDefend` ID，但显示名称不加角色前缀。

## 核心规则

### 生机

生机是战斗内资源，显示为 Power 层数。每获得 1 点生机，本场战斗的临时最大生命增加 1 点，但当前生命不会同时增加。战斗结束时清除所有生机，并移除本场战斗获得的临时最大生命。

为避免“消耗生机”造成突然降低最大生命并立即扣血，当前草案采用以下规则：消耗生机只减少资源层数，不在战斗中回收已经获得的临时最大生命；临时最大生命统一在战斗结束时回收。若战斗结束后当前生命超过原始最大生命，则将当前生命限制到原始最大生命。

生机的设计目标是“先积累，再把资源转成一次性收益”，而不是永久生命成长。卡牌中的“拥有至少 X 点生机”检查当前层数，“消耗 X 点生机”在结算时最多消耗实际拥有的层数。

### 麻痹

麻痹是施加在敌人身上的可叠加临时状态，建议 ID 为 `NineSwordTechniques:Paralysis`。每获得 1 层麻痹，目标本回合的力量和敏捷各降低 1；在目标回合结束时清除本回合的麻痹，并恢复被降低的力量和敏捷。它不是永久削弱，也不应跨回合保留。

同一回合内追加麻痹时，追加几层就追加几层属性降低；移除时必须只恢复本 Power 实际降低的数值，避免和其他减力量、减敏捷效果互相覆盖。目标死亡、战斗结束或 Power 被强制移除时也要完成清理。

卡牌描述中的“目标有 X 层麻痹”指结算瞬间的当前层数。麻痹流派应围绕“施加、达到阈值、在清除前引爆”循环，不依赖无限叠层；单张牌的麻痹伤害或收益应设置上限。

### 人格

人格是可跨角色使用的状态，不与 `MuzixiCharacter` 类型绑定：

- 木子汐人格：每回合开始获得 3 点格挡和 1 点生机。
- 泪汐儿人格：进入该人格时，消耗所有灵魂共鸣；每消耗 1 层，抽 1 张牌并获得 1 点能量。
- 人格交替及其他切换效果：每次切换人格抽 1 张牌。
- 无人格状态：角色同时没有木子汐人格和泪汐儿人格标记时，不触发任何人格效果。
- 任意角色通过外部效果获得对应人格 Power 后，都应触发对应效果；其他角色不会默认获得任何人格。

## 卡池结构

目标卡池共 60 张：4 张基础、24 张普通、20 张罕见、12 张稀有。

- 生机主轴：积累生机、根据当前生机达到阈值、消耗生机转化为格挡、治疗、抽牌或能量。
- 麻痹主轴：对敌人施加麻痹、根据麻痹层数获得额外效果、在敌人回合结束前引爆麻痹。
- 人格与混合牌：提供切换、灵魂共鸣以及同时连接两条主轴的收益，避免卡组只能单走一个方向。

表中的现有 ID 已在源码中注册；标记为“规划”的 ID 是本次新增的设计占位，后续实现时应保持 ID 稳定。所有 ID 的完整前缀均为 `NineSwordTechniques:`。

## 流派与构筑目标

### 生机流

生机流的基本循环是“萌芽、落叶舞、生机奔涌等牌积累资源，使用阈值牌获得额外收益，再用世界树、万花、青木奇迹等牌转化资源”。卡组需要同时提供防御和有限治疗，避免只靠临时最大生命拖延战斗。

建议的数值边界：

- 普通牌单次获得 1-3 点生机；罕见牌单次 3-6 点；稀有牌单次 6-12 点。
- 1 能量的生机消耗牌通常转化为 8-12 点格挡、一次抽牌或小额治疗；不同时提供全部收益。
- 根据生机的阈值主要使用 4、5、6、8，避免所有卡牌都依赖同一阈值。
- 临时最大生命只作为战斗内缓冲，不应被设计成永久成长或稳定替代格挡。

### 麻痹流

麻痹流的基本循环是“用花粉、根须和藤蔓施加麻痹，在目标回合结束前用断脉、神经崩解或神经断灭引爆”。由于麻痹会在目标回合结束时清除，玩家需要安排出牌顺序，而不是无限堆叠等待。

建议的数值边界：

- 普通牌通常施加 1-3 层麻痹；罕见牌 4-5 层；稀有牌的全体效果 6-8 层。
- 依赖麻痹阈值的普通牌使用 3-5 层，罕见牌使用 4-6 层。
- 按麻痹层数增加的伤害必须设置单张牌上限，建议普通牌最多额外 5-7 点，稀有牌最多额外 16-24 点。
- 麻痹的力量、敏捷修改必须由 Power 记录并恢复，不得直接永久修改敌人属性。

### 人格与混合流

人格交替、觉醒、神魔之眼和两仪归一负责把两条主轴连接起来。人格交替本身只提供换人格和抽牌，额外能量需要生机阈值或其他牌支持；这样无人格状态、单人格卡组和跨角色获得人格时都能保持清晰行为。

## Power 与动作

| Power ID | 名称 | 规则 |
| --- | --- | --- |
| `Vitality` | 生机 | 保存当前生机层数；每获得 1 层增加 1 点本场战斗临时最大生命；战斗结束时清除并移除临时最大生命 |
| `Paralysis` | 麻痹 | 敌方临时状态；每层使目标力量和敏捷降低 1，目标回合结束时清除并恢复本 Power 实际降低的数值 |
| `MuzixiPersona` | 木子汐 | 持有者回合开始获得 3 点格挡和 1 点生机 |
| `TearPersona` | 泪汐儿 | 进入该人格时消耗所有灵魂共鸣，每层抽 1 张牌并获得 1 点能量 |
| `Evergreen` | 常青 | 每获得 1 点生机，获得常青层数的格挡 |
| `NaturalCycle` | 自然循环 | 回合开始获得指定数量的生机 |
| `AncientBark` | 远古树皮 | 回合结束时生机至少为 4，则获得指定数量的格挡 |
| `HarmonicSoul` | 灵魂共鸣 | 进入泪汐儿人格时转化为抽牌和能量；转化后清空层数 |

`SwitchPersonaAction` 负责移除旧人格、施加新人格、抽取切换牌收益，并触发灵魂共鸣转化。它不负责给所有角色默认分配人格。`WorldTreeAction` 负责计算实际可消耗的生机并转化为格挡。麻痹需要独立的敌方 Power 或等价状态动作，不能复用玩家的临时属性修改逻辑。

## 药水现状

当前没有木子汐专属药水类、药水注册或药水本地化条目。角色使用游戏本体和其他模组提供的通用药水。后续若加入专属药水，应同时补充药水实现、BaseMod 注册入口、ZHS/ENG 本地化、图标资源和角色专属掉落规则。

## 数值基准与测试重点

数值应对标本体同稀有度卡牌，而不是单独追求每张卡都能形成完整连招：

- 基础打击、防御保持本体起始牌水平，分别为 6/9 伤害和 5/8 格挡。
- 普通攻击通常为 6-9 点伤害，升级增加 3-4 点；普通防御通常为 5-8 点格挡，升级增加 3-4 点。
- 罕见卡允许提供持续 Power 或双条件，但 1 能量牌不应同时给出高伤害、高格挡和大量资源。
- 稀有卡可以改变整套构筑的上限，但应通过 2-3 能量、消耗、阈值或每回合限制控制爆发频率。
- 生机和麻痹的收益必须受战斗节奏限制，避免靠 0 费牌无限增加资源、无限抽牌或无限触发 Power。

首轮测试应重点检查：生机获得后临时最大生命是否正确显示且不误回血；消耗生机是否不会在战斗中造成意外扣血；麻痹在敌方回合结束时是否完整清理并恢复属性；无人格状态是否完全无额外效果；其他角色获得人格 Power 后是否按同样规则触发；所有依赖“当前麻痹层数”和“当前生机层数”的牌是否在清除或消耗前完成判定。

## 后续实现顺序

1. 先实现 `Vitality` 和 `Paralysis` 的确定版规则及测试，再扩展卡牌。
2. 优先实现 4 张基础牌、已有 21 张非基础牌和两条主轴的规划普通牌，验证卡池节奏。
3. 按普通、罕见、稀有顺序补齐剩余卡牌、本地化和插图资源。
4. 最后根据实战数据调整阈值、费用、每回合限制和稀有牌的上限，不在未验证机制前一次性改大量数值。
