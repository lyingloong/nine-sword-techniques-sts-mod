# 九大剑术 (Nine Sword Techniques)

> 九大剑术，十八剑流，三千剑道，皆自剑楼收录剑祖出。——《我有一身被动技》  
> The Nine Great Swordsmanship, the Eighteen Sword Styles, and the Three Thousand Swordsmanship Paths—all originated from the Sword Ancestor recorded in the Sword Tower. — I Have a Body of Passive Skills

《杀戮尖塔》九大剑术主题模组。模组加入九张稀有无色基础剑术牌，以及可通过“顿悟”替换获得的九张特殊无色进化牌，并围绕剑术构筑扩展遗物、事件和涅奥奖励。

[Steam 创意工坊页面](https://steamcommunity.com/sharedfiles/filedetails/?id=3554467601)

## 模组内容

- 九张基础剑术牌与九张一一对应的顿悟形态。
- 七件主题遗物：所有角色共有的初始遗物、顿悟遗物、剑术增益遗物，以及烬照和虚空结晶系列遗物。
- 三个事件：白窟、虚空岛、八尊谙。
- 可选角色木子汐：使用“生机”和“一体双魂”体系，拥有独立的青绿色卡牌库、初始遗物与胜利场景。
- 涅奥普通奖励池中加入“选择一张剑术牌获得”的奖励，不额外占用一个固定选项。
- 提供简体中文与英文文本。

剑术牌使用以下专属规则：

- **真实伤害**：按生命流失结算，不受力量、虚弱、易伤等常规伤害修正影响。
- **返回**：卡牌结算后返回手牌。
- **鬼剑系牌**：鬼剑术与御魂诡术共享本场战斗的伤害增益。
- **出鞘剑**：攻击伤害按层数指数翻倍，`n` 层对应 `2^n` 倍伤害。

## 顿悟

顿悟时，从牌组中选择一张尚未进化的基础剑术牌，将其替换为对应的进化牌。替换会继承原牌的升级状态、UUID、瓶装标记及 `misc` 数据。

如果没有可进化的基础剑术牌，则随机升级一张可升级的牌，并获得 5 点最大生命。当前可由观剑典、白窟和虚空岛等效果触发。

| --- | --- |
| 藏剑术 / Hidden Sword | 出鞘剑 / Unsheathed Blade |
| 幻剑术 / Illusory Sword | 时空跃迁 / Spacetime Leap |
| 无剑术 / Non Sword | 无有剑流 / Void Blade Style |
| 万剑术 / Myriad Sword | 绝对帝制 / Absolute Imperial Rule |
| 情剑术 / Emotional Sword | 红尘剑·众生相 / Mortal Blade: All Living Faces |
| 莫剑术 / True Sword | 青河剑界 / Azure River Sword Domain |
| 鬼剑术 / Ghostly Sword | 御魂诡术 / Soul Control Trickery |
| 心剑术 / Mind Sword | 目下神佛 / Under One's Gaze |

## 木子汐

木子汐不使用剑术牌。她当前拥有 60 张专属卡牌，围绕战斗内资源“生机”、敌方状态“麻痹”和“一体双魂”构筑。获得生机会提高本场战斗的临时最大生命，超额失去生机则转化为凋萎；麻痹会暂时降低敌人的力量与敏捷。人格交替可在木子汐与泪汐儿之间切换：前者在回合开始时获得格挡和生机，进入后者时则最多消耗 9 层灵魂共鸣，每层提供 1 次抽牌和 1 点能量。人格不会跨战斗保留，其他角色获得对应人格 Power 时也遵循相同规则。

角色的完整卡牌表、初始配置和实现边界见 [木子汐角色设计](doc/muzixi-design.md)。角色美术资源按本体尺寸整理在 `src/main/resources/NineSwordResources/img/muzixi/`；新增卡牌的生成原图保留在 `tmp/gpt-image-2/cards_raw/`，提示词清单与总览图保留在 `tmp/imagegen/`。

| 遗物 | 稀有度 | 效果 |
| --- | :--: | --- |
| 剑祖的传承 | 初始 | 所有角色开局获得。仅可在战斗外右键使用一次：选择献祭或放弃。献祭失去 18 点生命，然后从基础剑术牌中选择一张获得；放弃无效果。 |

| 虚空结晶 | 特殊（事件） | 击杀敌人积累充能；每回合开始时，消耗 2 点充能并获得一层无实体。 |

## 安装

运行本模组需要：

- 《杀戮尖塔》
- ModTheSpire
- BaseMod

可直接通过上方 Steam 创意工坊页面订阅。手动安装时，将构建生成的 `nine-sword-techniques.jar` 放入游戏的 `mods` 目录，并通过 ModTheSpire 启动。

## 本地开发

项目使用 Java 8 与 Maven 构建。首次在本机开发时，需要根据实际安装位置调整：

- `pom.xml` 中的 `Steam.path`，用于定位游戏和依赖 JAR。
- `.vscode/settings.json` 中的 Java 8 路径。
- `.vscode/tasks.json` 中的 Maven 命令、`JAVA_HOME` 和 `PATH`。
- `.vscode/launch.json` 中的 `cwd`、`javaExec`、`classPaths` 和 `--mods` 参数。

执行构建：

```powershell
mvn clean package
```

`package` 阶段会生成 `target/nine-sword-techniques.jar`，并按照 `pom.xml` 的配置复制到游戏的 `mods` 目录。在 VS Code 中选择 `Run Mod` 调试配置后按 `F5`，会先运行 `maven-package` 任务，再通过 ModTheSpire 启动游戏。
